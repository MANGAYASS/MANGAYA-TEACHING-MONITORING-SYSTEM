SCHEDULE MANAGEMENT

Import, replace, add or delete schedules. The monitoring records remain separate for each schedule.

1. CREATE / SELECT SCHEDULE
2. IMPORT SCHEDULE FROM EXCEL / CSV / PDF

Recommended row format: DAY | CYCLE | SESSION | CLASS | SUBJECT | TEACHER. The importer also recognizes common header names.

3. MANUAL / PASTE DATA
4. TEACHER — SUBJECT — CLASS MASTER MAPPING

Upload Excel/CSV/PDF with TEACHER | SUBJECT | CLASS(ES). The system matches CLASS + SUBJECT and assigns the correct teacher.

Example: NJAYO CHANDE | CHEMISTRY | IA,IB,IC,ID. The system normalizes names and subjects automatically.
5. MANUAL TEACHER — SUBJECT — CLASS ASSIGNMENT

A teacher can be linked to up to 20 classes and up to 5 subjects. Choose FORM to display its classes. Daily/weekly periods are read from the selected timetable.

0 / 20 classes selected
Class options are FIA–FIL, FIIA–FIIL, FIIIA–FIIIL and FIVA–FIVL. The FORM selector changes the visible class list.
6. MASTER DATA — TEACHERS, SUBJECTS & CLASSES

Manage names and codes without changing the monitoring engine. A manually typed teacher is added to the teacher list when an assignment is saved.

TEACHER MASTER — EDIT NAME
SUBJECT MASTER — EDIT SUBJECT NAME & SHORT CODE
CLASS MASTER — CHOOSE FORM THEN EDIT CLASS NAME

How it works: MANGAYA sends the SMS request to SMSGate Cloud, SMSGate routes it to this online Android device, and the phone sends the SMS through the selected SIM. Keep SMSGate running and the phone connected to the internet.
Columns: TEACHER | PHONE. You can also include SUBJECT and CLASS columns.
